Math

Minerva renders LaTeX math wherever it appears in a note — inline in a sentence or as its own centered display equation — using the same $…$ / $$…$$ convention as Pandoc and most markdown-flavored notes apps. Rendering happens through KaTeX, so it's fast and works offline: no server round-trip, no network dependency.

Syntax

Wrap LaTeX in single dollar signs for inline math, doubled dollar signs for a block display equation.

$…$
Inline. Renders in place, mid-sentence. Example: the update rule is $\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$.
$$…$$
Block. Renders as its own centered display equation. Example: $$\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$$

A block equation can open and close on one line, or span several — the closing $$ just needs to end its own line:

$$
P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}
$$

How math renders

Inline math renders directly in the flow of text at normal size. Block math renders inside a bordered card — the same visual treatment as a code block — with the equation centered and the card scrolling horizontally if the equation is too wide to fit.

A $$…$$ pair written mid-paragraph (not at the start of a line) still renders in display mode, just without its own card — useful for a one-off large equation you don't want to break out of the sentence.

Malformed LaTeX doesn't break the preview

An equation KaTeX can't parse renders as an inline error span showing the raw source, rather than failing the whole note's preview. Hovering the error span shows KaTeX's parse error as a tooltip, so you can see exactly what's wrong without leaving the note.
